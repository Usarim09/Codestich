# Code Connector — Chrome Extension

Code Connector helps you merge, label, and export code snippets from multiple sources across the web. It's designed for developers who want to streamline their workflow without switching between tabs or copy-pasting endlessly.

Features:
- Automatically collects copied code
- Lets you merge and organize snippets
- Export all code as a single file

Coming soon: Screenshots, demo video, and install instructions.

---

## How to Use
1. Install via Chrome Web Store (coming soon) or load as an unpacked extension.
2. Copy code blocks while browsing.
3. Open the extension popup to view, label, organize, and export them.

---

## Tech Stack
- Chrome Manifest V3
- Vanilla JavaScript
- Local storage for saving snippets
